# Veloso Solution - Security Incident Response Procedure

## Purpose
This procedure defines how Veloso Solution identifies, records, contains and responds to security and personal data incidents.

## Incident Identification
Potential incidents include unauthorized access, credential exposure, personal data disclosure, environment isolation failure, suspicious API activity and loss of protected information.

## Immediate Response
When an incident is identified:

1. Record the incident and affected system.
2. Identify potentially affected data and users.
3. Contain the incident and prevent further exposure.
4. Revoke or rotate affected credentials when necessary.
5. Preserve relevant technical logs and evidence.
6. Correct the identified vulnerability or configuration issue.
7. Validate the correction before restoring normal operation.

## Personal Data
Veloso Solution evaluates whether personal information was accessed, altered, disclosed, lost or otherwise affected.

## Notification
When an incident affects data received through a partner platform, Veloso Solution will notify the relevant partner when required by applicable obligations and provide available information regarding impact, containment and remediation.

Affected users and competent authorities will be notified when required by applicable law or contractual obligations.

## Data Requests
Requests to access, correct or delete personal data are reviewed and processed after appropriate identity verification.

## End of Cooperation
Personal data collected through an integration will be deleted or anonymized when it is no longer required for the authorized purpose, subject to applicable legal retention obligations.

## Responsibility
Security incidents are reviewed by the system administrator responsible for Veloso Solution infrastructure and applications.

## Review
This procedure is reviewed whenever a significant security incident or material infrastructure change occurs.
