O plugin

Instala no Claude Code e orquestra o fluxo do dev

De ponta a ponta: padrão de commit, documentação, gate de qualidade e controle de token.

Com o plugin

Benefícios do plugin

  • Padroniza commit, branch e documentação automaticamente
  • QA-Gate no pre-commit: só sobe código no verde
  • Comandos prontos (/qa-init, /qa-gate) — configura o projeto sozinho
  • Reduz consumo de tokens e mantém contexto entre sessões
Sem o plugin

O custo de não ter

  • Cada dev usa a IA do seu jeito — código sem padrão
  • Bug de UI passa pro QA e volta dias depois
  • Configuração manual, repetitiva e sujeita a erro
  • Gasto de token sem controle
O motor

O MCP — simulação em navegador real

O servidor MCP dirige um navegador real e devolve o resultado estruturado — com screenshot — direto pro seu agente.

◉

O que o MCP faz

  • Sobe o fluxo em Chrome real, injeta o bug e valida o retorno
  • Exige mensagem amigável no DOM + console SEVERE = 0
  • Pega lib quebrada e hidratação errada que o teste unitário não vê
  • Validação de licença offline — seu código não sai da sua máquina
⌘

Onde roda

  • Feito para o Claude Code — governança e fluxo ponta a ponta
  • Núcleo portável a outros agentes/CI via MCP (compatibilidade sob demanda)
  • Usa o Chrome do sistema — não baixa nada pesado
  • Backend puro pula o browser: custo zero quando não há UI
